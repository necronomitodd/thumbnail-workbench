THUMBNAIL WORKBENCH

User Documentation & Guide

Welcome to Thumbnail Workbench—a fast, 100% offline desktop application built for creators to layout, compose, and export custom video thumbnails and slide decks without the bloat of heavy software[cite: 8].

Core Workflow

  1. Import Assets: Drag and drop background images, cutout subjects, or logos directly onto any slot polygon on the canvas, or click Upload in the sidebar card[cite: 8].
  2. Manage Slots: Reorder your images instantly using the drag handles (⋮⋮) next to each slot letter badge[cite: 8].
  3. Layout & Seams: Toggle between Layout Mode (Unlocked) and Art Director Mode (Locked) via the top bar[cite: 8]. When unlocked, drag the red middle handles (M) to move dividing bars together[cite: 8].
  4. Composition: Add customizable text overlays and transparent sticker cutouts via the sidebar tabs, adjusting font styles, strokes, outer glows, and rotations freely[cite: 8].

Export Settings & Resolution Guide

  • Copy Slide (Cmd + V): Instantly copies a high-resolution 4K render straight to your system clipboard, ready to paste directly into PowerPoint[cite: 8].
  • Export 1080p (JPEG): Renders an optimized 1920x1080 export engineered to keep your final file size safely under the strict 2MB compression limit required for YouTube video thumbnails[cite: 8].
  • Export 4K (PNG): Generates an uncompressed, crystal-clear 3840x2160 master file ideal for presentation slide decks[cite: 8].

Pro Tip: Thumbnail Workbench runs entirely offline. Your assets never touch a cloud server, ensuring 100% data privacy[cite: 8].
