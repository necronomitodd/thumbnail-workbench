macOS Security Note (Gatekeeper Bypass)

Because Thumbnail Workbench is distributed independently, macOS may show a prompt saying it is damaged and can't be opened the first time you launch it. To fix this instantly:

  1. Open your Applications folder.
  2. Hold down the Control key and click (or right-click) the Thumbnail Workbench icon.
  3. Choose Open from the context menu, then click Open on the warning dialog.

You will only need to do this one time!
