Installation & Security Guide

Troubleshooting first-time launch warnings on macOS and Windows for Thumbnail Workbench.

macOS: Bypassing Gatekeeper & "Damaged" File Warnings

Because Thumbnail Workbench is distributed independently without an expensive Apple Developer ID certificate, macOS Gatekeeper may flag the app as damaged or untrusted upon first launch.

To clear the web-download quarantine attribute and run the app normally, open your Terminal app and run the following command:

xattr -cr /Applications/thumbnail-workbench.app

Followed by an ad-hoc local signature sign command if needed:

codesign --force --deep --sign - /Applications/thumbnail-workbench.app

Windows: SmartScreen Prompt

When running the installer on Windows, Windows Defender SmartScreen may display an unrecognized app warning because the binary is self-signed.

  1. Click on the "More info" text link on the blue SmartScreen prompt.
  2. Click the "Run anyway" button that appears at the bottom.
