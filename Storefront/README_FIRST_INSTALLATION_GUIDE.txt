THUMBNAIL WORKBENCH (v0.1.0) - QUICK INSTALLATION GUIDE
====================================================================
Thank you for downloading Thumbnail Workbench! 

Because this is an independent software release, macOS and Windows 
will show a standard one-time security prompt the very first time 
you open the app. Follow the quick steps below for your system:

--------------------------------------------------------------------
FOR MAC USERS (macOS Apple Silicon & Intel)
--------------------------------------------------------------------
1. Double-click "thumbnail-workbench_0.1.0_universal.dmg".
2. Drag "Thumbnail Workbench.app" into your "Applications" folder.
3. Open your Applications folder, RIGHT-CLICK (or Control-Click) on 
   "Thumbnail Workbench" and select "Open".
   * Note: If macOS Sequoia/Sonoma says "Apple could not verify...", 
     open System Settings -> Privacy & Security, scroll down to the 
     Security section, and click "Open Anyway" next to Thumbnail Workbench.
   * Alternately, run this one-line command in Terminal to clear the flag:
     xattr -cr "/Applications/Thumbnail Workbench.app"

--------------------------------------------------------------------
FOR WINDOWS USERS (Windows 10 & Windows 11 - 64-bit)
--------------------------------------------------------------------
Option A: Standard Installer ("thumbnail-workbench_0.1.0_x64-setup.exe")
1. Double-click the setup.exe file.
2. If a blue "Windows protected your PC" (SmartScreen) window appears:
   - Click "More info" (underneath the text)
   - Click the "Run anyway" button at the bottom.
3. Follow the installer wizard to add Thumbnail Workbench to your Desktop.

Option B: Portable Version ("thumbnail-workbench_0.1.0_x64-portable.exe")
1. No installation required! Place the file anywhere and double-click.
2. If SmartScreen appears, click "More info" -> "Run anyway".
